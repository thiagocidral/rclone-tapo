Política de Privacidade — rclone-tapo

Última atualização: 10 de novembro de 2026.

O rclone-tapo é usado exclusivamente pelo seu próprio dono, para guardar no Google Drive dele as gravações das câmeras da casa dele.

  • Dados acessados: somente o Google Drive da conta que autorizou o app, para gravar e apagar os arquivos de backup das câmeras.
  • Uso: os dados não são lidos para nenhuma outra finalidade, não são vendidos, compartilhados nem transferidos a terceiros.
  • Armazenamento: o token de acesso fica apenas no servidor doméstico do dono. Nenhum dado é enviado a outro servidor além do Google.
  • Revogação: o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
